# 🚀 Team Task Manager (Full Stack Web Application)

A full-stack Task Management System built using **React, Node.js, Express, and MySQL**.  
This project helps users create, manage, update, and delete tasks efficiently with a clean REST API architecture.

---

---

## 🛠️ Tech Stack

### Frontend:
- React.js
- Axios
- HTML5, CSS3, JavaScript

### Backend:
- Node.js
- Express.js

### Database:
- MySQL (MySQL Workbench)

### Deployment:
- Railway (Backend)
